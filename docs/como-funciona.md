# Como funciona

1. **Coleta** — reunião das bases de dados de origem.
2. **Consolidação e tratamento** — padronização, limpeza e organização dos dados.
3. **Indicadores** — definição e cálculo dos indicadores operacionais.
4. **Visualização** — painel em HTML, CSS e JavaScript, acessível pelo navegador.
5. **Uso** — os indicadores apoiam a comunicação institucional e a tomada de decisão.
